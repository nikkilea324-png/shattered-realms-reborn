# Shattered Realms

A dark fantasy turn-based strategy game combining D&D-inspired heroes and encounters with Risk-inspired territory control and armies.

## Current status

**Foundation reset — clean project**

The old shattered-realms repository remains untouched as historical reference. This repository is the new technical foundation.

## First milestone

Build the Ravenwood vertical slice:

1. World map
2. Territory selection
3. Ravenwood 24×16 hex map
4. Terrain elevation
5. Commander and army pieces
6. Movement and turn state
7. Hidden cave discovery
8. Small playable dungeon

## Design principle

The game should feel like moving pieces across a living painted fantasy atlas, while retaining the depth of a tactical D&D-inspired campaign underneath.

## Development

Godot 4.x, Android-first, 3D-ready.
